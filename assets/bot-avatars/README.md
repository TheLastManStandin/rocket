# Аватарки ботов

Кладите сюда картинки — `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif` или `.svg`.
Больше ничего делать не нужно: сервер читает папку при старте и раздаёт файлы
по адресу `/bot-avatars/<имя файла>`.

Аватарка достаётся примерно девяти ботам из десяти. Какая именно — решает имя
бота, а не случай, поэтому «Мурка» всегда выглядит одинаково, и те же десять
процентов имён всегда остаются с буквой на цветном кружке.

Папка пустая — все боты с буквами, как раньше. Добавили файл — перезапустите
сервер, чтобы он его увидел.

Квадратные картинки от 128×128; в списке они рисуются кружком 36×36.
