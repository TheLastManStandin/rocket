# Racketka

Игра Crash как Telegram Mini App. Бекенд на Go, фронтенд на React, только мобильная вёрстка.

У каждого игрока своя независимая игра: свой коэффициент, своя точка краша и свой
набор ботов, который генерируется заново под каждый раунд. Ничего общего между
игроками нет — список внизу экрана целиком серверная декорация.

## Запуск

```bash
docker compose up -d          # Postgres на 5433
cp .env.example .env          # впишите BOT_TOKEN, если DEV_MODE=false
cd web && npm install && npm run build && cd ..
go run ./cmd/server           # http://localhost:8090
```

Миграции применяются на старте сами. `DEV_MODE=true` пускает без Telegram,
подставляя тестового игрока, — так приложение открывается в обычном браузере.

Разработка фронтенда с горячей перезагрузкой: `cd web && npm run dev` (порт 5173,
запросы и сокет проксируются на Go).

## Проверка внутри Telegram

```bash
make telegram
```

Поднимает базу, собирает фронт, запускает сервер и публичный HTTPS-туннель, а в
конце печатает адрес. Его и нужно указать в BotFather: `/newapp` → выбрать бота →
Web App URL. Токен того же бота должен лежать в `BOT_TOKEN`, `DEV_MODE=false`.
`JWT_SECRET`, если пуст, генерируется при первом запуске и дописывается в `.env`.

Туннель поднимается через `cloudflared`, если он установлен, иначе — по ssh через
`localhost.run`, для которого ставить ничего не нужно. Адрес у обоих одноразовый:
после перезапуска его придётся заново прописать в BotFather. Ctrl+C останавливает
и сервер, и туннель.

## Переменные окружения

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `ADDR` | `:8090` | адрес HTTP-сервера |
| `DATABASE_URL` | `...localhost:5433/racketka` | строка подключения к Postgres |
| `BOT_TOKEN` | — | токен бота; обязателен при `DEV_MODE=false` |
| `JWT_SECRET` | — | секрет сессионных токенов; обязателен при `DEV_MODE=false` |
| `DEV_MODE` | `false` | пускать без проверки подписи Telegram |
| `START_BALANCE` | `0` | стартовый баланс нового игрока |
| `HOUSE_EDGE` | `0.04` | преимущество заведения, RTP = 1 − edge |
| `MAX_CRASH` | `1000` | потолок коэффициента |
| `MIN_BET` / `MAX_BET` | `10` / `100000` | границы ставки |

## Как устроено

| Пакет | Отвечает за |
|---|---|
| `internal/telegram` | проверка подписи initData (HMAC-SHA256) |
| `internal/auth` | сессионные JWT |
| `internal/game` | кривая, точка краша, автомат раунда, боты |
| `internal/session` | горутина на игрока, реестр подключённых |
| `internal/wallet` | движение баланса; журнал обязан объяснять баланс |
| `internal/payments` | счета в звёздах и приём платежей |
| `internal/storage` | Postgres, миграции, игроки |
| `internal/ws` | веб-сокет |
| `internal/httpapi` | авторизация, статика, один origin |

Несколько решений, которые стоит знать, прежде чем что-то менять:

- **Коэффициент — целые сотые (`Multiplier`), не float.** На сравнении с ним
  рассчитываются деньги, а `2.50`, которое на самом деле `2.4999999`, оплатит
  ставку не в ту сторону.
- **Момент выхода считает сервер по своим часам** в момент получения запроса.
  Значение, которое рисует клиент, не участвует в расчёте.
- **`Advance` не ходит в БД.** Кошелёк дёргается только на явных действиях
  игрока, иначе поход в базу тормозил бы отрисовку кривой.
- **Границы фаз привязаны к расписанию, а не к моменту срабатывания тикера** —
  иначе раунд растягивается и разъезжается с обещанным клиенту отсчётом.
- **Цель выхода бота помечена `json:"-"`.** Бот, вышедший на x5, выдал бы, что
  раунд долетит хотя бы до x5.
- **Пополнение зачисляется по `telegram_payment_charge_id`** под уникальным
  индексом в журнале. Telegram может доставить обновление о платеже дважды, и
  вставка занимает платёж раньше, чем двинется баланс.
- **Платежи читаются long polling, а не вебхуком.** Вебхуку нужен постоянный
  публичный адрес, а разработка идёт за туннелем с новым адресом каждый запуск.

## Тесты

```bash
go test ./...
```

Тесты `internal/storage` идут против настоящего Postgres и пропускаются, если
базы нет. Адрес можно задать через `TEST_DATABASE_URL`.

## Чего здесь нет

Ставки подарками и инвентарь, Магазин, Задания, Арена, Кейсы, экран «Честность».
Точка краша берётся из `crypto/rand` без commit-reveal, поэтому игрок не может
проверить результат сам.

Баланс — это звёзды Telegram, одна к одному, и пополняется он через кнопку
баланса. Вывода нет: звёзды только приходят.
